# Where the reference photographs came from

The images themselves are not in the repo — see README.md for why. This file
is the record of what is on disk, so the licence and the photographer survive
even though the file does not.

## Freely licensed

Fetched from Wikimedia Commons. Credit and licence are recorded here because
CC BY and CC BY-SA require it of anyone who republishes the image, and a
filename is not attribution. Nothing here has been republished — these were
drawn from, not shipped — but the record costs nothing and the obligation
outlives anyone's memory of where a file came from.
