# Reference photographs

The 8-bit scenes are drawn by hand, but not from memory. This is where the
photographs they were drawn from live, one folder per scene, named for the
scene's id in `src/data/scenes.ts`:

| folder | scene | place | has a photo |
| --- | --- | --- | --- |
| `bund/` | The Bund | Shanghai | yes |
| `gugong/` | The Forbidden City | Beijing | yes |
| `tsinghua/` | Tsinghua Second Gate | Beijing | yes |
| `tianjin/` | Jiefang Bridge | Tianjin | — |
| `shenzhen/` | Lianhua Hill Park | Shenzhen | yes |
| `victoria/` | Victoria Harbour | Hong Kong | — |
| `tokyo/` | The Skyline | Tokyo | — |
| `fuji/` | Mount Fuji | Yamanashi | — |

The folders without one were drawn from something that was never saved here.

## Nothing in here is committed

This file is the only tracked thing in the folder. Everything else is ignored,
on purpose: the photographs are working material, and most of them belong to
whoever took them. This repo is public, so a photograph sitting in it is a
photograph being republished — which is not ours to do for an image we only
looked at.

The drawing is what ships. Once a scene is in the reel it owes its photograph
nothing but the shapes, and the shapes are already in `scenes.ts`.

## If a photograph really should ship

Then it has to be one that may be. In order of least trouble:

1. **Take it yourself.** Then it is yours to license, and it can be committed
   with everything else.
2. **Use a free licence** — CC0, CC BY, or public domain. Wikimedia Commons
   has all eight of these places. Credit the photographer and name the licence
   next to wherever it is used; CC BY is not satisfied by a filename.
3. **Buy it.** A stock licence usually permits this; the watermarked preview
   never does.

Anything else stays here, unread by git, and the pixels are the deliverable.
